# JsonGHCFiles


JsonGHCFiles is a project from Peñalara.  Peñalara is a Spanish company with more than 20 years of experience. We provide the reference software for the creation of school timetables around the world. More information about at [Peñalara Website](https://www.penalara.com)

Maven project which contains the specification of the Json format of output file it may got from the new PeñalaraGHC's timetable engine.

The projects contains:

 - Java POJO classes.
 - Markdown Documentation about classes structure.

## JSON Schema documentation

The documentation is generated from the JSON Schemas using JSON Schema for Humans:

- [Planning data](docs/planningData.schema.md)
- [Engine input and results](docs/ghcEngine.schema.md)
- [Engine output](docs/ghcEngineOutput.schema.md)
- [Multiplatform planner](docs/ghcMultiplatform.schema.md)
